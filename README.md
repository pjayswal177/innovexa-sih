# KandaGrade AI

Static onion quality assessment demo. It runs directly from this folder and stores saved assessments in the current browser.

## Publish with GitHub Pages

1. Put this folder in a GitHub repository and push the `main` branch (the workflow also accepts `master`).
2. In the repository, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**.
3. Open the **Actions** tab and wait for **Deploy to GitHub Pages** to finish. The workflow prints the public URL in its deployment environment.

The workflow redeploys on each push to `main` or `master`; it can also be started manually from the Actions tab.

Camera access is available on HTTPS public pages. Assessment history is browser-local and is not shared between visitors or devices. The photo grades and price bands are illustrative estimates, not certified grading or live market prices.
